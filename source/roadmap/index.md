这是博客的内容导航，也是我从通信硬件走向智能通信的长期学习路线。每一个主题都会从概念和工具，走向电路、代码、实验与项目。

## 01 · 电路与信号链

`模拟电路` → `AGC` → `有源滤波` → `功率放大` → `信号完整性`

已有实践覆盖录音屏蔽装置、有源二分频装置与 LoRa 音频链路。下一步会补充滤波器设计计算、仿真对比、器件非理想因素和测试方法。

## 02 · PCB 与硬件验证

`原理图` → `器件选型` → `PCB 布局` → `焊接调试` → `示波器验证`

主要使用 Altium Designer，并结合 Proteus、Multisim 完成仿真与方案检查。目标是建立一套可复用的硬件设计检查清单。

## 03 · 嵌入式与无线通信

`STM32` → `硬件接口` → `LoRa` → `系统联调` → `物联网应用`

从智慧农眼和 LoRa 双向通信项目出发，继续补齐驱动、协议、异常处理与系统可靠性知识。

## 04 · 软件与可复现实验

`Python` → `Linux` → `Git` → `数据处理` → `实验自动化`

目标是让硬件测试数据能够被自动采集、分析和复现，也让每次项目迭代都有清晰记录。

## 05 · 深度强化学习与智能通信

`机器学习基础` → `PyTorch` → `MDP` → `DQN / PPO` → `通信资源优化`

这是正在拓展的方向。不只记录算法公式，也记录奖励设计、训练曲线、失败实验，以及它与无线资源优化、低空网络决策之间的连接。

- 一份面向未来自己的学习总结。
